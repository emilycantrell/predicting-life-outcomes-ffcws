# Analysis

This directory contains code and supporting files for processing job outputs and conducting the analyses reported in the paper. The scripts in this directory are not used to run jobs or train machine learning models.

## Directories

### `figures_and_analyses_for_paper`

Contains code for the analyses, figures, and tables reported in the paper and appendix.

### `metadata_for_analysis`

Contains metadata used by the analysis code.

### `process_outputs_for_analysis`

Contains code for processing raw job outputs into files used for analysis.
