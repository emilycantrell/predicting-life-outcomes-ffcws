# Figures and analyses for paper

The script `figures_and_analyses_for_paper.R` generates all figures, tables, and numerical results for the paper and places the outputs in a local directory called `figures_and_tables/`.

One of the outputs of this script is `results_and_metadata_for_all_outcomes_*.csv`. A version of this file from the time of manuscript submission called `results_and_metadata_for_all_outcomes_manuscript_submission.csv` is posted in the `precomputed_results/` directory.
