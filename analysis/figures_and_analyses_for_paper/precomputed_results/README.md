# Precomputed results

Each time the script `figures_and_analyses_for_paper.R` is run, it produces a file named `results_and_metadata_for_all_outcomes_*.csv`, where the asterisk represents the date on which the script was run. This file contains results and metadata for all outcomes analyzed in the paper. For the public repository, we made a copy of the version generated at the time of manuscript submission and named it `results_and_metadata_for_all_outcomes_manuscript_submission.csv`. This frozen copy corresponds to the results reported in the manuscript submitted to the journal and posted to arXiv. As discussed in the paper, these results were generated using only half of the available data (these results *n* = 2,121; full data *n* = 4,242).

## Contents of `results_and_metadata_for_all_outcomes_*.csv` 

* `r2_cv_for_winning_pipelines`, `lower_ci_for_winning_pipelines`, and `upper_ci_for_winning_pipelines`: The $R^2_{CV}$ and associated confidence intervals for the winning pipelines. 
* `r2_cv_for_benchmark_pipeline`, `lower_ci_for_benchmark_pipeline`, `upper_ci_for_benchmark_pipeline`: The $R^2_{CV}$ and associated confidence intervals for the benchmark pipeline: a pipeline with standard scaling, selection of the top feature based on its linear association with the outcome, and a linear or logistic regression model.
* `sample_size_before_cross_validation_splits`: The sample size before the nested cross-validation splits are applied, i.e., the sum of the outer test fold sample sizes. Note: in the `_manuscript_submission` file, this column refers to the sample size within the half of the data that we are using prior to journal review. These sample sizes will change after journal review.
* `outcome_was_in_FFC`: Whether the outcome was studied in the Fragile Families Challenge (FFC). We include this column instead of the FFCWS metadata column `in_FFC_file`, because `in_FFC_file` refers to whether a variable was a feature in the FFC data, rather than an outcome.
* `measured_at_earlier_wave`: An indicator we created of whether the outcome was measured at an earlier wave, as described in "Identifying Whether a Construct Was Previously Measured" in our supplemental materials. 
* `focal_person`: A column we generated by combining information from the metadata columns starting with "fp_".
* `is_scale`: A column we generated to indicate whether the outcome is a scale. FFCWS scales are defined [here](https://ffcws.princeton.edu/data-and-documentation/scales-and-concepts-documentation). This is different than the "scale" column from the original FFCWS metadata, which indicates the scale of which a variable is a component, when applicable. 
* `section_name`: The name of the survey section the variable came from.
* All other columns come from the FFCWS metadata. They are described [here](https://metadata.ffcws.princeton.edu/). We made minor edits to the `varlab` column to improve readability; these edits do not change the substantive meaning of the variable labels. 

For outcomes that we constructed ourselves following the FFCWS scales instructions, we created our own metadata using the FFCWS metadata format.

Abbreviations used in `results_and_metadata_for_all_outcomes_*.csv` are as follows: ADD/ADHD: attention-deficit or attention-deficit/hyperactivity disorder; BMI: body mass index; BSI: Brief Symptom Inventory; CBCL: Child Behavior Checklist; CES-D: Center for Epidemiologic Studies Depression Scale; CHAOS: Confusion, Hubbub, and Order Scale; CIDI: Composite International Diagnostic Interview; CIDI-SF: Composite International Diagnostic Interview--Short Form; CPS: Child Protective Services; EPOCH: Engagement, Perseverance, Optimism, Connectedness, and Happiness; GPA: grade point average; SNAP: Supplemental Nutrition Assistance Program; SSDI: Social Security Disability Insurance; SSI: Supplemental Security Income; and TANF: Temporary Assistance for Needy Families.
