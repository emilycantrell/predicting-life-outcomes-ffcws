# Docs

To run a job, follow either the local setup guide or Azure setup guide. To produce figures, tables, and numerical results like the ones in our paper using the outputs of your job, you can then run the scripts in [`analysis/figures_and_analyses_for_paper/`](../analysis/figures_and_analyses_for_paper/). 

### `1-Local-Setup.md`

Instructions for running jobs on your local computer. This is only appropriate for jobs with a small number of outcomes or a small number of pipelines.

### `2-Azure-Setup.md`

Instructions for running jobs on Azure, which is where we generated the results in our manuscript. Note that to complete a run on Azure, the prerequisites require following part of the instructions from `1-Local-Setup.md` for the initial setup.

### `3-Troubleshooting.md`

Possible solutions for issues you might encounter when trying to run a job.
